# Word Document Inspector
Live Formatting & Selection Analyzer Add-in for Microsoft Word.

## Prerequisites
1. Node.js (v14+ recommended)
2. Microsoft Word (Windows, Mac, or Web)

## Installation & Running the Dev Server
1. Create a folder named `word-document-inspector`.
2. Save `package.json`, `manifest.xml`, and the `/src` folder structure exactly as provided.
3. Open your terminal in the root folder and run:
   ```bash
   npm install
